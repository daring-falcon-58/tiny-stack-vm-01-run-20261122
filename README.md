A faithful interpreter of make.fun's tiny stack ISA v1. `node main.ts` runs the 40 programs in `/input` and writes `/output/<id>/stdout.bin` + `exit.txt`: all 10 traps with their own codes, 32-bit wrap, unsigned DIVU/MODU/LTU, 1M-step and 64K-output limits. Practice: 40/40, score 1,000,000 (baseline plain-vm: 670,000).
